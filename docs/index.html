Cómo crear un Reel nuevo

  1. Elige el tema Un consejo útil para el hogar (limpieza, mantenimiento, cómo elegir). Si no sabes por dónde empezar, abre una idea en GitHub.
    Proponer una idea de Reel
  2. Pídeselo a Claude Abre la carpeta del repositorio en Claude Code y pega una de estas peticiones. Claude propone el guion antes de hacer nada.
  3. Revisa el guion y el vídeo Comprueba que los consejos son ciertos, que la voz suena bien y que el texto se lee. Si algo no encaja, díselo a Claude y lo cambia.
  4. Abre un Pull Request Es la forma de enseñar el cambio al otro antes de publicarlo. Claude puede dejarlo preparado.
  5. Aprobar es fusionar Cuando el otro está de acuerdo, cambia el estado de la pieza a approved y fusiona. Se publica sola a su hora.

Preguntas frecuentes

¿Cuándo se publica una pieza?

Cada hora, GitHub revisa la cola. Publica la primera pieza en estado Aprobado cuya hora ya haya llegado (como mucho una por ejecución). Los borradores nunca se publican.

¿Cómo apruebo o rechazo una pieza?

En “Calendario”, pulsa “Aprobar en GitHub”. Se abre el archivo de la cola: cambia "status": "draft" por "approved" en la pieza correspondiente y guarda con “Commit changes”. Para retirarla, vuelve a poner draft.

¿Cómo cambio la fecha o el texto?

En el mismo archivo, edita scheduled_at (hora UTC; en octubre España va 2 horas por delante) o caption. La web se actualiza en unos minutos.

¿Qué pasa si falla una publicación?

La pieza pasa a “Falló” y el motivo aparece en su tarjeta. No se reintenta sola: corrige el problema y cambia el estado otra vez a approved.

¿El token de Instagram caduca?

Sí, a los 60 días. El repositorio abre un aviso los días 1 y 20 de cada mes. Se renueva con node megahogar-reels/publish/instagram.mjs --refresh-token y se actualiza el secreto IG_ACCESS_TOKEN.

¿Se puede publicar un carrusel?

De momento no automáticamente. Las imágenes están en megahogar-carrusel/slides y se suben a mano desde el móvil.

¿Cuánto cuesta cada Reel?

Unos 2 céntimos de voz con ElevenLabs. Los clips de Pexels, los sonidos, GitHub y la API de Instagram son gratis.

¿Por qué no se ve mi cambio en este panel?

El panel se reconstruye al fusionar cambios y una vez por hora. Espera unos minutos y recarga la página.
